## Project QGIS
---
Folder penelitian ini berisi file proyek aplikasi QGIS 3.42.2

Penelitian ini menggunakan QGIS untuk:

- Mengolah data titik lokasi minimarket
- Melakukan teknik buffer analysis
- Menghasilkan raster buffer minimarket
- Melakukan zonal statistics untuk menghitung jumlah penduduk
- Menghasilkan jumlah penduduk yang tercakup radius buffer
- menyusun hasil visual peta menjadi laporan.
